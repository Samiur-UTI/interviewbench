# Frontend tasks

Web UI tasks (components, state, client-side data fetching). Create one with
`ib new <task-id> --category frontend --template <template>`; see docs/TASK_FORMAT.md. There is
no frontend template yet: use `--template backend-python` and replace the stack, or add one
under `templates/`.

- `campaign-console`: marketing console (TypeScript, Preact SSR, WebSocket): phantom disconnects and a pentest finding, reconnect-and-resume, shared probes.
