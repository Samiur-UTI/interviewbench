# Changelog

All notable changes to this project are listed here, in the [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) format.

## [Unreleased]

### Added

- The `cluster-cutover` task, the first in the `devops` category: a Kubernetes and Vault platform repo whose hidden tests simulate the cluster and Vault, so they need only Python.

## [0.1.0] - Unreleased

### Added

- The `ib` CLI: `list`, `start`, `test`, `next`, `prompt`, `grade`, `break`, `validate`, `new`, `ui` and `version`.
- The local browser GUI, which opens with `ib` or `ib ui`.
- Three tasks: `rate-limiter`, `flight-search-aggregator` and `campaign-console`.
- The AI judge, with Claude, OpenAI-compatible and pasted-reply backends.
- Docker and local runners for task scripts.
- Tasks run as Harbor tasks.
